# Uso de IA durante o desenvolvimento

Utilizei ferramentas de inteligência artificial como apoio durante este
projeto.

Elas me ajudaram principalmente em:

- explicações sobre TypeScript, Fastify e SQLite;
- revisão de erros encontrados durante os testes;
- sugestões de organização das pastas;
- revisão da documentação;
- levantamento de cenários de teste.

Não publiquei código com credenciais ou informações privadas. Todos os dados
usados são fictícios.

Antes de manter uma alteração, executei o projeto e os testes localmente. Meu
objetivo com este repositório não é fingir que desenvolvi tudo sem ajuda, mas
mostrar como uso IA para aprender, testar ideias e construir uma solução que
consigo explicar e continuar evoluindo.
